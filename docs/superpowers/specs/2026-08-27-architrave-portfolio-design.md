# Architrave Portfolio - 静的サイト移行 設計書

## 背景・目的

現行の `architrave.myportfolio.com`(Adobe Portfolio)はナビゲーション配置などの細かいレイアウト調整ができず、カスタムCSSの直接編集も不可(コードが自動的に除去される仕様)。同じ内容を自前の静的サイトとして再構築し、GitHub Pagesで無料公開することで、レイアウトを完全にコントロールできるようにする。

## スコープ(このフェーズ)

- 元サイトのトップページに表示されている作品のうち**最初の6〜9件**を再現したプロトタイプ
- 対象: ヘッダー(ナビ+ロゴ、ナビをロゴに寄せた配置)、作品グリッド、クリックでYouTube動画をモーダル再生
- 対象外(将来フェーズ): 残り約70件の作品追加、他ページ(制作実績/ご依頼について/GALLERY)の複製、独自ドメイン設定、本格的なレスポンシブ対応

## アーキテクチャ

静的サイト、ビルドツールなし(`pomodoro-timer/index.html` と同じ「単一構成・依存なし」の方針に合わせる)。

ファイル構成:
- `index.html` — マークアップ全体
- `style.css` — スタイル
- `script.js` — グリッド描画・モーダル開閉ロジック
- `data.js` — 作品データ配列
- `images/` — サムネイル画像(元サイトからダウンロードして自己ホスト。Adobe CDNへの直リンクはしない)

## コンポーネント

### ヘッダー
- 左: ナビゲーションリンク(HOME / 制作実績 / ご依頼について / GALLERY)。`text-align: right` でロゴ側に寄せて配置。
- 右: ロゴテキスト「ARCHITRAVE WORK」
- このフェーズでは複数ページ化はスコープ外のため、リンク先はダミー(`#`)でよい。

### 作品グリッド
- `data.js` の `works` 配列を `script.js` が読み込み、DOMに動的生成(3列グリッド、16:9サムネイル)
- サムネイルクリック → モーダルを開き、YouTube iframeを埋め込み再生
- モーダルは背景クリックまたは閉じるボタンで閉じる

### データモデル(`data.js`)
```js
const works = [
  { title: "エンドロール - クワガタP feat. 重音テト", year: 2026, youtubeId: "fepw6wKU8D8", thumbnail: "images/01.jpg" },
  // ...
];
```

## データフロー

1. ページロード時、`script.js` が `data.js` の `works` を読み込む
2. `works.forEach` でグリッドカードのDOM要素を生成し、コンテナに追加
3. カードクリック → モーダルの `iframe.src` を `https://www.youtube.com/embed/{youtubeId}` に設定して表示
4. モーダルを閉じる際は `iframe.src` を空にして動画再生を停止する

## エラーハンドリング / エッジケース

- 画像読み込み失敗時: `alt` 属性でタイトルを表示するブラウザ標準動作に任せる(追加のフォールバックUIは作らない)
- `works` が空の場合: グリッドが空表示になるだけで問題なし(今回は該当しないが将来的なガードは不要、YAGNI)

## テスト/検証方法

- ローカルで `npx serve` 等を使って配信し、ブラウザで目視確認
- 確認項目: ヘッダーのナビ位置(ロゴに近いか)、グリッドの列数・余白、モーダルでの動画再生、モーダルの開閉
- レスポンシブは簡易確認のみ(本格対応は次フェーズ)

## デプロイ

- GitHubリポジトリ `architrave-portfolio` を新規作成し、このフォルダをpush
- GitHub Pagesを有効化(main ブランチ / root ディレクトリ)
- 公開URL: `https://<ユーザー名>.github.io/architrave-portfolio/` で確認
